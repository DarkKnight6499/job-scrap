## Behavior

- Teamtailor prefers `/jobs.rss`, reads RSS items, deduplicates numeric job IDs, and maps title, link, description, publication date, location elements, and remote status. Missing or invalid dates stay blank. RSS pages use `offset` in steps of 100. Repeated pages and the `max_pages` ceiling, default 40, return incomplete results. A missing or malformed RSS feed falls back to `/jobs` links and per-job JSON-LD. HTTP 403, 429, and server failures propagate.
- Comeet discovers inline JS settings, widget data attributes, or an embedded careers API URL. It calls `https://www.comeet.co/careers-api/2.0/company/<uid>/positions?token=<token>&details=true` with a 60-second timeout. The documented top-level list supplies `uid`, `name`, `location`, `url_active_page`, `time_updated`, and `details[].value`. Missing active URLs fall back to `url_comeet_hosted_page`. Update dates use `posted_source="approx"`. Missing credentials and non-list responses raise errors. External scripts are not executed or fetched.
- Kula reads the public careers page, follows same-host job links, and uses `_public_job_detail`, `_jobposting`, and `_posting_location` for per-job JSON-LD. It accepts `/onshore/<numeric id>-<title>` and `/onshore/jobs/<numeric id>` links. Missing JSON-LD retains the visible title and description; absent locations and dates stay blank. It does not guess a JSON API endpoint or a `__NEXT_DATA__` schema.
- HTML lists deduplicate IDs. Explicit empty-board text can establish an empty board; unknown pages remain incomplete. Advertised counts above the discovered total and `rel="next"` pagination remain incomplete. HTML pagination is not followed. Unmarked client-side pagination cannot be detected.
- `describe()` supports all three sources. It preserves Comeet's approximate list date instead of replacing it with a detail-page date.
