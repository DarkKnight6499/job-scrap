Job Description: Job Title: Associate Location: Cary, NC Overview DB Global Technology, Inc. seeks an Associate in Cary, NC to architect distributed systems and APIs that support high-volume, low latency financial transactions. Requires a Bachelor’s degree in Computer Engineering, Computer Science, or a related field or equivalent and two (2) years of experience designing and optimizing APIs using Java Spring Boot; writing JUnit test cases to ensure functionalities adhere to requirements; developing testing programs and protocols to facilitate regression testing, error/bug retests, and usability using Selenium and Cucumber; writing and reviewing software documentation using Confluence to ensure technical accuracy, compliance, and completeness to mitigate risks; developing frontend UI pages using React and Redux based on UI/UX mockups; refining functional requirements to provide input on product designs, schedules, and potential problems; monitoring product performance as part of a production support team to ensure functionality; and utilizing AI-driven technologies including GitHub Copilot to increase efficiency and promote rapid development. Salary range: $98,450.00 - $140,000.00/year. This position is eligible for Deutsche Bank's Employee Referral Incentive Program.
