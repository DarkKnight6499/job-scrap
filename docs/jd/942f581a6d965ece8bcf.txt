Job Description As a valued colleague on our team, you will design, develop, test, and/or maintain moderately complex hardware, technology, and/or processes. Access Management Engineer Collaborate and coordinate with customers to gather and evaluate business requirements and design automated test methodologies providing coverage for product delivery. •Lead a team of SDETs in building test strategies and framework design to test complex API, web and mobile based applications that reference database back-end systems. •Build test automation frameworks from scratch with Selenium, Pytest, Cucumber, Junit, TestNG, Applitools, Microsoft Graphs, Sauce Labs, Mavin, Jenkins, and Java. •Perform mobile testing and build frameworks with technologies and tools including Appium, Appium Desktop, UIAutomator2, XCUITest, Android, IOS, AndroidStudio. •Build and maintain Jenkin pipelines and jobs for automated tests system with resource monitoring tools including OS-native tools and popular resource monitoring and log analysis stacks (ELK, Splunk, Kibana). •Perform functional testing with a focus on functional test definition and test planning, test automation at all levels of the testing pyramid, and scalability testing in large scale, distributed systems. •Perform different testing methodologies, such as behavior-driven testing, regression testing, e2e testing, user acceptance consumer-driven contract testing, unit testing, and integration testing. •Summarize test results into meaningful reports to effectively communicate test coverage and code quality, as well as scalability, capacity and performance issues. •Review product scalability, reliability, consistency, and performance. •Mentor less experienced team members and share best practices in testing methodologies This is a Flex position, limited remote work possible. REQUIREMENTS: Master’s in Computer Science or Telecommunications and at least three years of experience as Developer in Test using Java, Python, Jenkins, GitLab, GitHub, Bitbucket, Cucumber, AWS services (including S3, EC2, CloudWatch, DynamoDB, Lambda, IAM), Applitools, Selenium, Maven, Microsoft Graphs, RestAssured, SQL, Postman, OAUTH 2.0, Appium, Android, IOS, XCUITest, UIAutomator2, LINUX shell scripting, PING products (including Ping One, Ping Identity, Ping Federate, Ping Directory, Ping Access), Splunk, and Kibana.
