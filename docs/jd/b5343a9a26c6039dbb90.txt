Test Automation Associate
JPMorgan Chase
Location: Wilmington, DE, United States
Link: https://jpmc.fa.oraclecloud.com/hcmUI/CandidateExperience/en/sites/CX_1001/job/210806442

Join us to improve customer experiences by raising quality and delivery speed through automation. You will build reliable automated tests that help teams release changes safely and confidently. As a Test Automation Analyst in our Credit Card team, you design, build, and maintain automated tests and an in-house automation framework for critical customer workflows. You work closely with product and technology partners to turn requirements into test scenarios, reduce test flakiness, and surface quality risks early. You help establish practical testing standards so the team can deliver changes with confidence. Job responsibilities Design, develop, and maintain automated functional, end-to-end, and regression tests. Maintain and enhance an in-house automation framework to improve stability, speed, and readability. Translate acceptance criteria into clear test scenarios and effective test plans. Build maintainable test code using reusable patterns (for example, page objects) and shared utilities. Create stable element locator strategies and explain tradeoffs between approaches. Diagnose and resolve common automation failures (for example, missing elements, timeouts, and stale elements). Automate API validation and support manual testing when automation is not feasible. Integrate automated tests into build and release pipelines to continuously validate changes. Communicate test progress, results, and issues to partners and stakeholders. Participate in team ceremonies (refinement, planning, reviews, and demos) and contribute to continuous improvement. Required qualifications, capabilities, and skills Bachelor's or Master's degree in Computer Science or a related field. 1 year of experience maintaining test automation frameworks. 1 year of experience manually testing APIs using tools such as Postman or Bruno. Strong hands-on experience with Selenium and a test framework such as Cucumber. Working knowledge of Java and the ability to explain core concepts used in day-to-day automation work. Understanding of web fundamentals (HTML, CSS, and JavaScript) to support reliable automation. Ability to select and implement stable locator strategies (for example, IDs and CSS selectors) and describe when other approaches are needed. Ability to use appropriate wait strategies to make tests reliable and avoid hard-coded delays. Experience using version control and collaborating through code reviews and feature branching. Experience using continuous integration and build tools (for example, Jenkins and Maven). Strong communication skills, including the ability to clearly explain testing decisions, results, and risks. Preferred qualifications, capabilities, and skills Experience working in financial services and familiarity with credit card products. Experience automating modern front ends, including elements inside shadow roots. Experience integrating automation with external tools or data sources (for example, spreadsheets, screenshots, or databases). Experience designing and validating tests on cloud-based platforms and services. Experience working in Unix-based environments. Working knowledge of Python in addition to Java.
