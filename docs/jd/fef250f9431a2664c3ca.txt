Job Description Development Lead, RBC Capital Markets, LLC, Jersey City, NJ: Design and development solutions for Capital Markets application using various advanced, J2EE, Python libraries and frameworks. Work with architecture teams to document and review architect, design for solutions spanning across regulatory, transformative projects. Develop unit test cases to ensure application is fully tested and document results. Plan, Coordinate and Manage application releases using ServiceNow approval process. Design and develop applications on various RDBMS databases Oracle, SQL Server and Postgres. Lead and Manage team of developers to deliver large scale applications. Review code from team to ensure they comply to coding standards. Review and approve timesheets for reporting team members. Work closely with business and functional analysts to understand the project requirements and design technical feasibility, solutions. Participate in agile sprint planning to plan and deliver code modules aligning to project timelines and scope. Create project status updates for working group and steerco meetings. Model wireframes and develop UI using ReactJS, AngularJS UI, JQuery frameworks. Work with infrastructure teams to plan infrastructure needs for project delivery. Create infrastructure requests that aligns to project requirements. Work with run the bank team to plan application production rollouts, design application monitoring controls. Provide L3 support to troubleshoot and perform issues analysis. Review application with risk team to identify, document and remediate risk items. Work with internal audit teams to review. Ensure code modules are labelled, uploaded to configuration management tools GitHub, SVN. Configure applications on Docker containers for optional usage of compute fabric platforms. JUNIT design and development for unit testing the solutions developed. #LI-DNI Full-time employment, Monday – Friday, 40 hours per week, $189,592.00 per year.
