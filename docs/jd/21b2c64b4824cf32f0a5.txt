Machine Learning Engineer About the Role As a Machine Learning Engineer at Analog Devices, you will play a key role in developing and implementing machine learning models that enhance our semiconductor solutions. You will work independently on ML projects while collaborating with cross-functional teams to deliver innovative solutions. This position offers the opportunity to apply your ML expertise to solve real-world problems in signal processing, sensor data analysis, and edge computing applications. Key Responsibilities: Develop and implement ML models independently Perform feature engineering and data preprocessing Conduct model evaluation and optimization Contribute to ML pipeline development Collaborate with data scientists and engineers Must Have Skills: Python Programming : Strong programming skills with proficiency in developing efficient and maintainable code ML Frameworks : Experience implementing solutions using modern machine learning frameworks and tools Data Modeling : Ability to create effective data models and apply appropriate preprocessing techniques Model Optimization : Knowledge of methods to evaluate and optimize ML model performance Pipeline Development : Understanding of ML deployment processes and pipeline development Preferred Education and Experience Bachelor's or Master's degree in Computer Science, Data Science, or related field 2-5 years of experience in machine learning or related field.
