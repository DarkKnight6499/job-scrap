About the Role: Grade Level (for internal use): 12 The Team: The SGA Application Security team operates as a strategic security partner, combining Application Security, DevSecOps, Exposure Management, and AI Security capabilities to proactively reduce risk while enabling innovation. Our collaborative, fast-paced culture emphasizes automation-first approaches, developer partnership, and continuous learning in emerging technologies. Team members gain exposure to enterprise-wide security transformation initiatives, AI-powered security tools, and opportunities to solve complex challenges that impact global engineering teams. Responsibilities and Impact: Lead complex application security assessments across multiple testing methodologies — including SAST, SCA, DAST, API security, secrets detection, and threat modeling — to identify and mitigate security vulnerabilities across the enterprise. Drive integration of security controls into developer workflows across GitHub, Azure DevOps, Jenkins, and cloud-native platforms, implementing risk-based quality gates that enhance secure coding practices. Perform comprehensive threat modeling and security design reviews for new applications, APIs, and cloud services, providing strategic guidance on secure architecture decisions. Design and implement AI-enabled Application Security capabilities — including custom tools, agents, and automations — that improve security testing, triage, and remediation while meeting enterprise governance standards. Partner with cross-functional teams including engineering, product, cloud, and risk stakeholders to resolve systemic application risks and establish scalable security controls across the SDLC. Provide technical leadership and mentoring to security analysts and engineering partners while contributing to enterprise standards, procedures, and audit-ready documentation. What We're Looking For: Basic Required Qualifications: Bachelor's degree in Cybersecurity, Computer Science, or Engineering. 6+ years of experience in Application Security, DevSecOps, secure software. Demonstrated proficiency in application security testing methodologies including SAST, SCA, DAST, threat modeling, and CI/CD security integration. Demonstrated experience integrating security controls into GitHub, Azure DevOps, Jenkins, or cloud-native delivery environments. Demonstrated experience using generative AI and AI-assisted development tools to build custom security tooling, scripts, integrations, or automations. Additional Preferred Qualifications: Experience with Model Context Protocol (MCP), AI agents, agentic architectures, tool calling, and retrieval-augmented generation for secure enterprise AI integration. Experience with cloud application security across AWS, Azure, and GCP, with understanding of cloud-native security controls in multi-cloud environments. Proficiency in Python, PowerShell, or equivalent scripting languages to automate and improve security operations at enterprise scale. Experience with software supply chain security initiatives including dependency governance, artifact management, provenance validation, and trusted package consumption. Demonstrated ability to communicate complex security risks to senior stakeholders and drive remediation across distributed engineering teams. Experience providing technical mentorship within security or engineering teams.
